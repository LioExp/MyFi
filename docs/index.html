How it Works

Three layers.
Clear separation.

MyFi separates concerns into Core, Chunks, and Plugins — like puzzle pieces that only fit where they belong.

1

Core Engine

Network discovery, traffic capture, and data persistence — the foundation that never changes.

2

Chunks (Logic)

Business modules you enable or disable: Scanner, Monitor, Limiter, Alerts, Reports — each does one thing well.

3

Plugins (Capabilities)

Technical tools that Chunks use: Telegram, Geolocation, Honeypot, Forensic Timeline — mix and match freely.
