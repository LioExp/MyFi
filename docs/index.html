Features

Everything you need
to own your network

From simple device discovery to programmable limits and plugins — MyFi turns network management into a visual, intuitive experience.

📡
Network Scanner
Discover every connected device with IP, MAC address and hostname. Passive and active detection in seconds.
myfi scan
📊
Traffic Monitor
Track real-time data consumption per device. Visualise usage peaks and patterns over time.
myfi monitor
⏳
Usage Limits
Set monthly or daily quotas per device. Automatic alerts when a device exceeds its defined limit.
myfi limit
🔔
Telegram Alerts
Receive instant notifications when a device exceeds its limit or a new device joins your network.

See where external connections originate. Geolocation plugin with integrated visual map overlay.

How it works

Snap pieces together.
Own the stack.

MyFi separates responsibilities into three clear layers. Add or remove layers without touching core code. Each combination produces a different, purpose-built tool.

  • Core manages the network and exposes raw data
  • Chunks apply logic and business rules on top
  • Plugins provide external technical capabilities
  • Each piece fits exactly where it belongs
Security

Trust nothing.
Verify everything.

MyFi follows Zero Trust principles. Every device is untrusted until proven otherwise. Continuous monitoring, automatic alerts, and programmable limits keep your network safe.

🔒 Zero Trust Profiling

Each device gets a trust score based on its behavior. Suspicious activity triggers automatic isolation.

🍯 Honeypot Detection

Deploy silent traps on your network. Any device that probes them is instantly flagged as a potential intruder.

🛡️ Forensic Timeline

Reconstruct exactly what any device did on your network — when it connected, what it accessed, and when it left.

🔐 Telegram Alerts

Instant notifications when anomalies are detected. Never miss a security event on your network again.
